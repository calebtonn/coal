This folder holds drift review reports: `YYYY-MM-DD.md` for a general review and `YYYY-MM-DD-adr-NNN.md` for the snap list of one ADR, each a table of claims that the site, the docs and the code do not agree on, quoting the text it flags. A report is produced by running the `/drift-review` skill (`.claude/skills/drift-review/SKILL.md`) at the repo root, with the ADR number as its argument for a snap list; the maintainer commits reports, and a contributor files issues from the rows instead of opening a PR for the report.
