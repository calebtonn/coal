Dig up anything you built with AI.

COAL keeps a record of your work outside any one tool: what you meant to do, what got made, and what comes next. It lives in a folder on your machine, and any AI tool that speaks MCP can read it.

This is the spec and the plan. Nothing to install yet. The examples below show how the first release will work.

Level 2−90 m

Three things, kept outside any one tool.

For each thing you are working on, COAL keeps one record, called an Intent Manifest. It holds three things.

The intent, in your words

The first thing you asked for becomes the summary. You search for it later the way you said it, not the way a model paraphrased it.

The artifacts

Pages, scripts and docs, copied in and addressed by their SHA-256 hash, so the record survives a moved file or a deleted chat. Each one notes which tool and model made it.

The state

When you last touched it, the next step, and the questions still open. This is what lets the next session start where the last one stopped.

Level 3−180 m

It writes itself while you work.

Claude Code runs hooks at fixed points in a session. COAL listens to them. You do not fill in anything.

Claude Code comes first. Cursor, Codex CLI and Gemini CLI have hooks too, and they share one capture contract, so each new tool is a small adapter.

  1. SessionStart

    COAL finds the record for this folder and puts the next step on screen.

  2. PostToolUse

    Claude writes budget.html. COAL registers it as an artifact. On the first write it creates the record, using your first message as the summary, and drops a small .coal marker in the project.

  3. Stop

    After each turn, the last activity time moves forward. Nothing slower than that.

  4. SessionEnd

    A job is queued and the hook returns at once. Later, the next step and a short summary of where things stand get filled in.

Level 6−650 m

The format is the product.

Each record is one JSON file in ~/.coal/manifests/. You can read it with cat. Any tool can write one. The Intent Manifest schema is open, versioned, and published at coalmine.io/schema/intent-manifest/0.1.json.

~/.coal/manifests/019a3f2c….json
{
  "intent": {
    "summary": "Household budget tracker as a single HTML page",
    "source": "user"
  },
  "status": "active",
  "artifacts": [{
    "hash": "sha256:9f86d0…0a08",
    "title": "budget.html",
    "producer": { "tool": "claude-code" }
  }],
  "state": {
    "nextStep": "Add CSV export and a category edit dialog",
    "openQuestions": ["localStorage or a JSON file?"]
  },
  "contexts": [{ "kind": "path", "key": "~/projects/budget" }]
}
  • intent.sourceWho wrote the summary: you or a model. Search ranks your own words first.
  • artifacts[].hashThe identity of the file. The path is a hint; the hash is what survives.
  • state.nextStepThe line every resume starts from.
  • contexts[]Where this work belongs, so it can show up without a search.
  • provenanceEvery record says which tool wrote it. Never a token or a secret.
Level 7−800 m

Built so you can walk away from it.

The record is yours. If COAL disappeared tomorrow, every manifest and every artifact would still be a file you can open.

Local first

Everything lives in ~/.coal/. No account, no server of ours.

Files are the truth

Plain JSON is the record. The search index is SQLite and can be deleted and rebuilt from the files.

Your words first

The summary is what you said, not a paraphrase. A record in your own words is one you can find.

Nothing phones home

No telemetry. The daemon binds to 127.0.0.1 only. This page has no trackers either.

Never deletes

Remove means move to the trash folder. When git is installed, every change to a record is kept in its history.

Open, all of it

Apache 2.0: the schema, the library, the CLI and every adapter. No paid tier.
